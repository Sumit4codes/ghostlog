# GhostLog Backend API

Node.js backend server for crash log collection, storage, and management.

## 📋 Features

- ✅ **REST API**: RESTful endpoints for crash log management
- ✅ **SQLite Database**: Lightweight, serverless database
- ✅ **Crash Fingerprinting**: SHA-1 based crash grouping
- ✅ **Device Tracking**: Monitor all devices sending logs
- ✅ **Automatic Deduplication**: Group similar crashes
- ✅ **CORS Enabled**: Ready for frontend integration

## 🚀 Quick Start

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
# Install dependencies
npm install
```

### Run Server

```bash
# Production mode
npm start

# Development mode (with auto-reload)
npm run dev
```

Server runs on **http://localhost:3000**

## 🔌 API Endpoints

### Submit Crash Log

**POST** `/api/logs`

Submit a new crash log from a device.

**Request:**
```json
{
  "device_id": "GHOST-DEV-001",
  "fw_version": "1.0.0",
  "timestamp": "2025-11-22T02:40:51Z",
  "crash_log": "panic: null pointer dereference at 0x08001234"
}
```

**Response:**
```json
{
  "success": true,
  "crash_id": 1,
  "fingerprint": "a1b2c3d4e5f6...",
  "crash_type": "panic"
}
```

### Get All Logs

**GET** `/api/logs`

Retrieve all crash logs.

**Response:**
```json
{
  "success": true,
  "count": 10,
  "crashes": [...]
}
```

### Get Device Logs

**GET** `/api/logs/device/:deviceId`

Get crash logs for specific device.

**Response:**
```json
{
  "success": true,
  "device_id": "GHOST-DEV-001",
  "count": 5,
  "crashes": [...]
}
```

### Get All Devices

**GET** `/api/devices`

List all devices with crash counts.

**Response:**
```json
{
  "success": true,
  "count": 3,
  "devices": [
    {
      "device_id": "GHOST-DEV-001",
      "first_seen": "2025-11-22T02:00:00Z",
      "last_seen": "2025-11-22T02:40:51Z",
      "fw_version": "1.0.0",
      "crash_count": 5,
      "last_crash": "2025-11-22T02:40:51Z"
    }
  ]
}
```

### Get Crash Groups

**GET** `/api/crashes/groups`

Get crashes grouped by fingerprint.

**Response:**
```json
{
  "success": true,
  "count": 2,
  "groups": [
    {
      "fingerprint": "a1b2c3d4e5f6...",
      "crash_log": "panic: null pointer...",
      "count": 10,
      "first_seen": "2025-11-20T12:00:00Z",
      "last_seen": "2025-11-22T02:40:51Z",
      "affected_devices": "DEV-001,DEV-002",
      "affected_devices_count": 2,
      "crash_type": "panic"
    }
  ]
}
```

### Get Crash Group Details

**GET** `/api/crashes/group/:fingerprint`

Get all crashes for a specific fingerprint.

### Get Daily Statistics

**GET** `/api/stats/daily`

Get crash counts per day (last 30 days).

**Response:**
```json
{
  "success": true,
  "data": [
    { "date": "2025-11-22", "count": 5 },
    { "date": "2025-11-21", "count": 3 }
  ]
}
```

## 💾 Database Schema

### Devices Table

| Column | Type | Description |
|--------|------|-------------|
| device_id | TEXT | Unique device identifier (PRIMARY KEY) |
| first_seen | TEXT | First connection timestamp |
| last_seen | TEXT | Last connection timestamp |
| fw_version | TEXT | Current firmware version |

### Crashes Table

| Column | Type | Description |
|--------|------|-------------|
| id | INTEGER | Auto-increment ID (PRIMARY KEY) |
| device_id | TEXT | Device identifier (FOREIGN KEY) |
| timestamp | TEXT | Crash timestamp |
| fw_version | TEXT | Firmware version at crash time |
| fingerprint | TEXT | SHA-1 hash of normalized crash log |
| crash_log | TEXT | Full crash log text |
| created_at | TEXT | Record creation timestamp |

## 🔐 Crash Fingerprinting

Fingerprints are generated by:
1. Normalizing crash log (remove timestamps, addresses, numbers)
2. Computing SHA-1 hash
3. Using hash to group similar crashes

Example:
```
Original: "panic: null pointer at 0x080012AC, time: 2025-11-22T02:40:51Z"
Normalized: "panic: null pointer at 0xADDR, time: TIMESTAMP"
Fingerprint: "a1b2c3d4e5f67890abcdef..."
```

This allows grouping of crashes with same root cause but different specifics.
